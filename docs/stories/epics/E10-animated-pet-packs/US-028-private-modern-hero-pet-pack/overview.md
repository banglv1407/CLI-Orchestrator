# Overview

## Current Behavior

No private modern hero artwork exists. Bundled mythical sprites are 48x48,
four-frame pixel strips.

## Target Behavior

A local-only pack contains consistent 128x128 chibi pixel-HD animation for
Goku Ultra Instinct, Naruto Seventh Hokage, and the original Web Ranger
fallback, with two signature moves per pet.

## Affected Users

- The local pack owner.

## Affected Product Docs

- `docs/product/pets.md`

## Non-Goals

- Public redistribution, bundling, sound, or representing Web Ranger as
  Spider-Man.
